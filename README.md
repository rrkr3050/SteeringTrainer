# Steering Trainer — ステアリング＆ペダル入力波形評価トレーニングシステム

## 1. アプリケーション概要

**Steering Trainer** は、実車運転およびレーシングシミュレーター（Assetto Corsa等）におけるステアリング操作およびペダル操作（ヒール＆トゥ、アクセル波形追従、トレイルブレーキング）の品質を入力波形レベルで精密に分析・評価・トレーニングするためのWindowsネイティブ・デスクトップアプリケーション（WPF / .NET 8）です。

従来の単なる「舵角・ペダル開度表示ツール」とは一線を画し、ミリ秒単位・高周波（約500Hz）でセンサー値を直接計測。ドライバーが無意識に一定角速度で滑らかに操作できるステアリング技術、ブレーキ圧をブラさずに正確なブリッピングを行うヒール＆トゥ技術、そして**一定のブレーキ圧を維持しながら目標Sin波形に合わせてアクセルを滑らかに操作する波形追従技術（位相遅れ分析付き）**を科学的・定量的に育成することを目的としています。

### 最重要評価対象
1. **ステアリング角速度（$\omega$）の一定性**: 目標とする旋回速度を一定に維持できているか（Lock to Lock）
2. **ステアリング角加速度（$\alpha$）の平滑性**: 無駄なカクつきや急な力みがなく、滑らかに回せているか
3. **ヒール＆トゥ時のブレーキ踏力安定性**: アクセルをあおる（ブリップ）瞬間にブレーキが抜けたり余計に踏み込まれたりせず一定圧を維持できているか
4. **ブリップ量・タイミング精度**: 目標アクセル開度への到達と、ブレーキ安定後の素早い踏み込み・戻し速度
5. **アクセル波形追従性（Throttle Tracking）**: ブレーキを一定に維持したまま、目標Sin波形に合わせて正確に踏み込み・戻しができるか
6. **位相精度（Phase Lag）**: 目標波形の変化に対し、ドライバーの操作に何秒（ミリ秒）の遅れまたは進みが生じているか

## 2. 対応ハードウェア & 背景入力（非アクティブ受付）仕様

本システムは、DirectInput / Windows Game Controller 規格に準拠するすべてのステアリングコントローラー（Logicool / Logitech GTFP, G25, G27, G29, G923, Thrustmaster, Fanatec, Moza, Simagic 等）に対応しています。

### 非アクティブ・バックグラウンド入力対応
- **完全バックグラウンドサンプリング**: UIスレッドとは完全に分離された高精度バックグラウンドスレッド（`ThreadPriority.AboveNormal`）にて最高500Hzでポーリング・信号処理（`SignalProcessor`）を実行します。
- **イベント駆動評価**: サンプル到着イベント（`SampleProduced`）で直接判定・バッファ記録が行われるため、アプリが非アクティブ（別ウィンドウやゲーム画面を操作中）であっても評価落ちやサンプルの欠落が一切発生しません。
- **描画タイマーの優先度最適化**: UI更新タイマーに `DispatcherPriority.Render` を採用。WPFウィンドウがフォーカスを失ってもタイマーが抑制されず、リアルタイムに波形・メーターが描画され続けます。
- **ハンコンボタンでの開始・停止**: ステアリングコントローラーのボタン（GTFPのボタン等）を押すことで、非アクティブ状態のまま練習の「開始 / 停止」をトグル操作可能です。シムレース画面から手を離さずに操作できます。
- **「常に最前面」表示**: タイトルバーの「常に最前面」にチェックを入れることで、Assetto Corsa等のボーダレス/ウィンドウ画面の上に重ねてリアルタイムメーターを確認しながら練習可能です。

## 画面の使い方

各練習画面の冒頭に目的と開始・停止操作を表示しています。左側の内容が収まらない場合はスクロールして設定と判定を確認できます。練習中は目標と現在の入力を見比べ、終了後に履歴で結果を確認できます。

### [F1] LOCK TO LOCK（メインステアリング練習）
一定の角速度でステアリングを回し切る練習画面です。

#### 画面要素
1. **CURRENT INPUT (現在値パネル)**
   - **Angle**: 現在のステアリング角度（度、センター0°）。
   - **Velocity**: 現在のステアリング角速度（°/s、緑色表示）。
   - **Acceleration**: 現在のステアリング角加速度（°/s²、オレンジ色表示）。
2. **TRAINING CONFIG (目標設定パネル)**
   - **Preset**: プリセットコンボボックス。
     - Beginner (540° / 3.0s = 180.0°/s)
     - Normal (540° / 2.5s = 216.0°/s)
     - Fast (540° / 2.0s = 270.0°/s)
     - Advanced (720° / 2.5s = 288.0°/s)
   - **Lock Angle**: 目標切り角スライダー（180°〜900°）。
   - **Time per Side**: 片側所要時間スライダー（0.5s〜5.0s）。
   - **Target Velocity**: 計算された目標角速度（$LockAngle / TimeSide$）。
3. **REAL-TIME VERDICT (リアルタイム判定パネル)**
   - **判定表示**: 誤差5%未満で `GOOD`（緑）、15%未満で `WARNING`（黄）、それ以外で `MISS`（赤）。
   - **Velocity vs Target ゲージ**: 目標速度に対する現在速度の比率（1.0で目標一致）。
4. **操作ボタン**
   - **[START] / [STOP]**: セッションの開始/停止（キーボードの `Space` またはハンコンボタンでも操作可能）。
   - **STOP**: セッションの停止（`Esc` キーでも操作可能）。
   - **CSV エクスポート**: セッション中の500Hz全サンプル（時刻, Raw角度, Filtered角度, 角速度, 角加速度, 正規化値）をマイドキュメントへCSV出力。
5. **右ペイン (視覚化インジケータ)**
   - **STEERING POSITION**: ステアリング舵角のリアルタイムバー。
   - **Steering Acceleration Graph**: 直近8秒間の平滑化角加速度波形グラフ。

### [F2] HEEL & TOE（ヒール＆トゥ・ペダル練習）
ブレーキ圧を一定に維持しながら素早くアクセルをブリッピングする練習画面です。

#### 画面要素
1. **リアルタイム判定ヘッドライン**
   - **進行状況**: 試行回数およびスコア表示。
   - **ブレーキ離すまでの連続平均**: ブレーキを解除するまでの連続トライアル平均点。
   - **ステータスヘッダー**:
     - `STABLE`: 目標ブレーキ範囲内で安定中
     - `BLIP!`: ブリップ指示（高音シグナル）
     - `PERFECT` / `GOOD` / `MISS`: 判定結果と失敗理由の明示（例: Early Blip, Brake Unstable等）
   - **スコア内訳**: Brake安定性（50点満点）、タイミング（20点満点）、ブリップ量（30点満点）。
2. **PEDAL INPUTS (ペダル現在値インジケータ)**
   - **BRAKE**: 目標値（黄）、現在値（赤）、目標許容帯およびリアルタイムバー。
   - **THROTTLE**: 目標値（黄）、現在値（緑）、目標許容帯およびリアルタイムバー。
3. **HEEL & TOE TRAINING SETTINGS (詳細設定展開パネル)**
   - **目標ブレーキ量 / 許容ブレ幅**: 目標値（5%〜95%）と許容幅（±1%〜±15%）。
   - **目標アクセル量 / 許容ブレ幅**: 目標値（5%〜100%）と許容幅（±5%〜±30%）。
   - **フリー練習ランダム変更**: ブレーキ量・アクセル量を5試行ごとにランダムに変更するチェックボックス。
   - **ランダム目標値の出現割合制限（4つの調整バー）**:
     - ランダム選択有効時（フリー練習でチェックを入れた場合および10回チャレンジ時）に出現する目標値の範囲を制限する4本のスライダー。
     - **ブレーキ目標 最低値 (5%〜95%、5%刻み)**: 出題されるブレーキ目標割合の下限値。
     - **ブレーキ目標 最高値 (5%〜95%、5%刻み)**: 出題されるブレーキ目標割合の上限値。
     - **アクセル目標 最低値 (5%〜100%、5%刻み)**: 出題されるアクセル目標割合の下限値。
     - **アクセル目標 最高値 (5%〜100%、5%刻み)**: 出題されるアクセル目標割合の上限値。
     - **範囲制約と挙動ルール**:
       - 常に $最低値 \le 最高値$ となるよう自動調整（最低値を引き上げると最高値も連動、最高値を引き下げると最低値も連動）。
       - 最低値＝最高値に設定した場合はその割合値が固定で出題。
       - 出題値は5%刻みで指定区間内から等確率で選出。直前と同一ペアが連続した場合は可能な限り別ステップへ自動調整。
       - 「ブレーキ安定テスト（0.5秒保持）」の5回成功ごとの目標切り替え時にも、このブレーキ出現範囲設定が適用。
   - **難易度**: Beginner / Normal / Advanced の判定閾値切り替え。
   - **効果音の音量 & 試聴**: 音量スライダーと「試聴」ボタン。
   - **手本モード**: 理想波形オーバーレイの表示/非表示。
   - **ブラインドモード**: 音響フィードバックのみで波形を見ずに練習するモード。
4. **モード選択ボタン**
   - **10回連続チャレンジ**: 10回の規定試行を行い、総合平均点と内訳、改善点を診断。
   - **フリー練習**: 自由に反復練習を行うモード。
   - **ブレーキ安定テスト（0.5秒保持）**: 目標ブレーキ量を踏み込んでから0.5秒間許容幅内に維持するまでの時間を計測。
5. **右ペイン (波形 & ヒートマップ)**
   - **練習タブ**: 直近3秒間のブレーキ・アクセル波形と手本波形のリアルタイム表示。
   - **結果マップ（チャレンジ）**: 目標ブレーキ量×目標アクセル量ごとの平均点を2次元カラーヒートマップ表示。
   - **結果マップ（フリー）**: フリー練習での組み合わせ別平均点ヒートマップ。
   - **ブレーキ保持履歴**: 目標ブレーキ量ごとの安定所要時間プロット。

### [F3] THROTTLE TRACKING（アクセル波形追従トレーニング）

#### 1. モードの目的とコンセプト
実車のコーナリング中やシムレースにおいて、**「ブレーキを一定圧（例: 50%や80%）に維持しながら、アクセルペダルを正弦波（Sin波）に沿って滑らかに踏み込み・戻す」**という極めて高度なペダルコントロール技術を習得するための専用練習モードです。
ブレーキの踏力を一切乱さずにアクセルを開閉できる独立運動能力と、狙った波形に対して遅れなく追従できるリズム・予見操作能力を育成します。

#### 2. 設定項目（6つの調整バー・スライダー）
設定パネル内の各スライダーにより、練習難易度や課題条件を自由にカスタマイズ可能です（練習中は誤操作防止のため無効化されます）。
- **目標ブレーキ量 (5%〜95%、5%刻み)**: 一定維持すべきブレーキペダルの踏力（例: 50%, 80%）。
- **ブレーキ許容幅 (±1%〜±20%、1%刻み)**: 目標ブレーキ量からの許容ブレ幅（例: ±5%）。この範囲内にある時間がブレーキ維持率として加点されます。
- **アクセル下限 (Min) (0%〜90%、5%刻み)**: 目標正弦波の最底値（例: 0%）。
- **アクセル上限 (Max) (10%〜100%、5%刻み)**: 目標正弦波の最高値（例: 40%, 80%）。
  ※ 常に $Min \le Max - 5\%$ となるよう自動制約が働き、反転や破綻を防止します。
- **アクセル許容幅 (±1%〜±20%、1%刻み)**: 目標正弦波からの許容ブレ幅（例: ±5%）。このバンド内に収まっている時間がアクセル追従率として加点されます。
- **波形速度 (BPM / 上ピーク基準) (4〜200 BPM、1 BPM刻み)**:
  目標正弦波の上のピーク（ThrottleMax）到達を「ワンビート（1拍）」としてBPMを計算（1分あたりのピーク到達回数）。
  1周期にかかる秒数は $T = \frac{60}{\text{BPM}}$（秒）となります。
  下限（最も早い状態）に余裕をもたせ、最大 200 BPM（1周期 0.30秒 / 300ms）まで設定可能。
  超低速（4 BPM $\implies$ 15.0秒、5 BPM $\implies$ 12.0秒）から標準テンポ（15 BPM $\implies$ 4.0秒、30 BPM $\implies$ 2.0秒）、高速トレーニング（60 BPM $\implies$ 1.0秒、120 BPM $\implies$ 0.50秒、200 BPM $\implies$ 0.30秒）まで幅広く調整できます。
- **練習時間 (10秒〜180秒、10秒刻み)**: セッションの規定継続時間（例: 30秒, 60秒）。
- **メトロノーム音 (上下ピーク音) チェックボックス & 音量スライダー**:
  - チェックをONにすると、目標Sin波の**下ピーク（アクセルMin到達時）**および**上ピーク（アクセルMax到達時）**の瞬間と完全に一致するタイミングでメトロノーム音が鳴ります。
  - セッション中（走行中）でも自由にON/OFFの切り替えおよび音量（0%〜100%）の微調整が可能。
  - 設定内容は次回起動時にも自動復元されます。

#### 3. 操作フローとステートマシン
1. **待機中 (Idle)**:
   - 「START [Space]」ボタンを押すか、キーボードの `Space` またはハンコンのボタンを押すと開始します。
2. **ブレーキ準備中 (WaitingForBrake)**:
   - 画面に「ブレーキを目標 ○○% (±○%) で約0.4秒安定させてください」と表示されます（黄色のステータス表示）。
   - 設定した目標ブレーキ値までペダルを踏み込み、許容範囲内で0.4秒間維持すると、自動的に追従セッションがスタートします。
3. **波形追従中 (Tracking)**:
   - ステータスが緑色になり、カウントダウンタイマーが作動します。
   - 右上のアクセル波形（目標Sin波）に合わせて、ペダルを滑らかに操作します。
   - 下段のブレーキ波形を見ながら、ブレーキ踏力が許容帯から外れないようキープします。
4. **セッション完了 (Finished)**:
   - 規定時間が経過するか、「STOP [Esc]」を押すとセッションが終了します。
   - リアルタイムに入力データを解析し、総合スコア（100点満点）、グレード、3大基本評価、詳細追従分析が左ペインに即座に表示されます。
   - セッション結果は自動的に SQLite データベース（`training-history.db`）に保存されます。
   - 再び `Space` を押すだけで即座に次のセッションに挑戦できます。

#### 4. 練習画面とリアルタイム波形描画仕様（OxyPlot 2段プロット）
- **上段グラフ: アクセル波形追従プロット（未来2秒先読みスクロール表示）**
  - **時間軸（X軸）**: 現在時刻を中心に $[t_{now} - 3.0, \, t_{now} + 2.0]$ 秒（過去3秒から未来2秒先まで）を自動スクロール表示。
  - **NOW カーソル**: 現在時刻（$t_{now}$）の位置に水色の垂直点線が表示されます。カーソルの右側が「これから訪れる未来の目標カーブ」、左側が「自分が操作した過去の軌跡」です。
  - **目標Sin波ライン（黄色実線）**:
    $$y(t) = min + (max - min) \times \frac{1 - \cos\left(\frac{2\pi t}{T}\right)}{2}$$
    $t=0$ で $min$ から微分係数0で滑らかに立ち上がるため、無理な急踏み込みが生じません。
  - **許容帯ライン（黄色破線）**: 目標値の上限（$+tol$）および下限（$-tol$）を破線で未来2秒先まで描画。
  - **実アクセル操作線（緑色太線）**: ドライバーの実際のペダル操作軌跡がリアルタイム描画されます。
- **下段グラフ: ブレーキ一定維持プロット**
  - **時間軸（X軸）**: 上段のアクセルグラフと完全に同期した $[t_{now} - 3.0, \, t_{now} + 2.0]$ 秒ウィンドウ。
  - **目標ブレーキライン（橙色破線）**: 設定された目標ブレーキ踏力。
  - **許容帯ライン（赤色破線）**: 上限（$+tol$）および下限（$-tol$）。
  - **実ブレーキ踏力線（赤色太線）**: アクセルを操作している間にブレーキがブレていないかをリアルタイム表示。

#### 5. 評価ロジックと計算式（100点満点・3大基本評価＋詳細分析）
総合スコアは 100 点満点で採点され、難易度（波形速度・振幅・許容幅）とともにSQLiteに記録されます。

```
総合スコア (100点) ＝ 波形精度スコア (40点) ＋ 位相精度スコア (30点) ＋ ブレーキ安定性スコア (30点)
```

- **グレード判定**:
  - `PERFECT`: 90.0点以上
  - `GREAT`: 75.0点〜89.9点
  - `GOOD`: 60.0点〜74.9点
  - `TRY AGAIN`: 59.9点以下

- **基本評価1: 波形精度スコア（40点満点）**
  - 目標Sin波の許容範囲内に収まった時間の割合（アクセル追従率 %）から算出:
    $$\text{WaveformScore} = \text{Clamp}\left(\text{ThrottleInToleranceRatio} \times 0.40, \, 0, \, 40\right)$$
- **基本評価2: 位相精度スコア（30点満点・位相遅れ分析）**
  - 目標波形を前後 $\tau \in [-0.8s, +0.8s]$ シフトさせた際の平均二乗誤差 $MSE(\tau)$ をグリッド探索し、ドライバーの操作の位相差（秒）を推定。
  - $|\tau| \le 0.05$秒（50ms以内）は神速の追従として満点30点。
  - $|\tau| \ge 0.50$秒（500ms以上の遅れ・進み）で0点となる線形減点。
  - 画面上には「位相差: +0.12 秒 (遅れ)」のように正負符号付きで明瞭に表示。
- **基本評価3: ブレーキ安定性スコア（30点満点）**
  - アクセル操作中のブレーキ維持率（%）から算出:
    $$\text{BrakeStabilityScore} = \text{Clamp}\left(\text{BrakeInToleranceRatio} \times 0.30, \, 0, \, 30\right)$$

- **詳細分析指標**:
  - **アクセル追従率 (%)**: 許容範囲内に収まっていた全時間の割合。
  - **ブレーキ維持率 (%)**: ブレーキが許容範囲内に収まっていた全時間の割合。
  - **同時達成率 (%)**: 両方のペダルが同時に許容範囲内に収まっていた時間の割合。
  - **踏み込み精度 vs 戻し精度**:
    - 踏み込みフェーズ（$\sin$ 増加区間）での平均絶対誤差（%）
    - 戻しフェーズ（$\sin$ 減少区間）での平均絶対誤差（%）
    - どちらの操作フェーズで誤差が大きくなるかを診断可能。
  - **踏み込み時ブレーキ維持率 vs 戻し時ブレーキ維持率**:
    - アクセルを踏み込む瞬間と、アクセルを抜く瞬間のどちらでブレーキが乱れやすいかを特定。

#### 6. メトロノーム音響フィードバック仕様（上下ピーク同期音）
- **目的**: 画面の波形を凝視せずとも、リズム感（テンポ感覚）と足の筋肉記憶（マッスルメモリー）で正確な開閉タイミングを習得可能にする音響ガイド機能です。
- **同期ロジックと音階**:
  - 正弦波の半周期 $\Delta t = \frac{T}{2} = \frac{30}{\text{BPM}}$ ごとに正確にピークが訪れます。
  - **上ピーク（アクセルMax到達時, $t = 0.5T, 1.5T, 2.5T, \dots$）**: 1760 Hz (A6), 25ms — クリアで抜けの良い高音メトロノームアクセント音。
  - **下ピーク（アクセルMin到達時, $t = 0.0T, 1.0T, 2.0T, \dots$）**: 1175 Hz (D6), 25ms — 落ち着いた中高音メトロノームティック音。
  - 急峻なアタック（2ms）と指数関数的減衰（$e^{-6 t / \tau}$）を合成したメモリ常駐WAVにより、高速BPM（最大200 BPM）でも遅延ゼロ・ノイズゼロの快適な打音を提供します。
- **UI操作**:
  - 左上カード（START/STOPボタン直下）の「メトロノーム音 (上下ピーク音)」チェックボックスで走行中いつでもワンクリックでON/OFFを切り替え可能。
  - 音量スライダー（0%〜100%）付き。

### [F5] SETTINGS（設定画面 & ペダル詳細校正・ガンマ調整）
デバイス選択、ステアリング設定、各ペダル（アクセル・ブレーキ・クラッチ）の詳細校正（0%/100%点のワンクリック取得、ガンマカーブ調整、上下端デッドゾーン）を行います。**設定内容はアプリ終了時または変更時に自動保存され、次回起動時に自動復元されます。**

#### 画面要素と詳細仕様
1. **Input Device (デバイス選択)**
   - 接続されているゲームコントローラー・ハンコン一覧から選択（GTFP、G29等）。
   - **デバイス更新**: USB抜き差し時にデバイス一覧を再スキャン。
   - **適用 & 保存**: 選択したデバイスを有効化し、即座に設定ファイルへ保存。
   - **保存ステータス表示**: 設定変更・保存のタイムスタンプを緑色テキストでリアルタイム表示。

2. **LIVE AXIS MONITOR (リアルタイム Raw 軸モニター)**
   - `X (Steer)`, `Y`, `Z`, `R`, `U`, `V` の6軸すべての現在Raw値（0〜65535）をミリ秒単位で表示。
   - ペダルを踏み込んだ際にどの軸の数値が変化するかを一目で把握できます（例: GTFPではアクセルがZ軸、ブレーキがR軸）。

3. **Wheel Settings (ステアリング設定)**
   - **Wheel Rotation (総舵角)**: 200° / 360° / 540° / 720° / 900° / 1080° から選択（GTFP標準は900°または200°）。
   - **Center Offset**: センター位置の微調整（-30.0°〜+30.0°）。
   - **Invert Input**: ハンドルの左右入力方向を反転。

4. **Pedal Input & Calibration (ペダル詳細校正 & ガンマ設定)**
   THROTTLE（アクセル）、BRAKE（ブレーキ）、CLUTCH（クラッチ / 任意）の各ペダルごとに、独立したカード型キャリブレーションUIが用意されています。

   ```
   +-----------------------------------------------------------------------------------------+
   | BRAKE (ブレーキ)   ※早期100%到達を防ぐにはガンマを1.5〜2.2へ調整   現在Raw: 65535  認識入力値: 0.0% |
   | [=====================================================================================] |
   | 割り当て軸: [ Axis R (4) ▼ ]    [v] 入力反転 (Invert)                                   |
   |                                                                                         |
   | [ 0%点 (未踏み時 Raw) ]                       [ 100%点 (最大踏み込み時 Raw) ]            |
   | [ 65535      ] [未踏み(0%)に設定]             [ 22000      ] [全踏み(100%)に設定]        |
   |                                                                                         |
   | 入力ガンマ (Gamma / カーブ特性): 1.8 (プログレッシブ: 奥で強く効く・踏み切り急増防止)     |
   | <---[============●================]--->                                                 |
   | ※ 1.0=直線。1.5〜2.2に設定すると踏み始め〜中盤が緩やかになり奥で強く踏むまで100%に達しにくくなります|
   |                                                                                         |
   | 踏み始め遊び (0%側): 2%                       踏み切り遊び (100%側): 2%                 |
   | <---[==●==========================]--->       <---[==●==========================]--->   |
   +-----------------------------------------------------------------------------------------+
   ```

   - **各ペダルの操作・設定項目詳細**:
     - **リアルタイムメーター & Raw表示**:
       - **現在Raw**: 割り当てられた軸のリアルタイム生値（0〜65535）をミリ秒単位で表示。
       - **認識入力値 (%)**: 正規化・デッドゾーン・ガンマ補正を経た最終的な入力割合（0.0%〜100.0%）。
       - **カラープログレスバー**: 直感的な視覚フィードバック（アクセル=黄緑、ブレーキ=赤橙、クラッチ=シアン）。
     - **割り当て軸コンボ**: `JoystickAxis.None`, `X`, `Y`, `Z`, `R`, `U`, `V` から選択。
     - **入力反転 (Invert)**:
       - チェックボックス。GTFPなど「ペダルを踏み込むとRaw値が小さくなる（65535 → 0）」機材では反転を有効化。
       - 0%点と100%点の大小関係（`Raw0Percent > Raw100Percent`）と完全連動し、ワンクリック校正時にも自動判定されます。
     - **0%点 (未踏み時 Raw) 設定**:
       - テキストボックスに数値を直接入力可能。
       - **「未踏み(0%)に設定」ボタン**: ペダルから完全に足を離した状態でこのボタンを押すと、現在のRaw値が瞬時に0%点（`Raw0Percent`）として取り込まれ、設定ファイルへ自動保存されます。
     - **100%点 (最大踏み込み時 Raw) 設定**:
       - テキストボックスに数値を直接入力可能。
       - **「全踏み(100%)に設定」ボタン**: ペダルを自分の足で限界まで踏み込んだ状態でこのボタンを押すと、現在のRaw値が瞬時に100%点（`Raw100Percent`）として取り込まれ、設定ファイルへ自動保存されます。
       - **ペダルの硬さ・途中到達問題の完全解決**: GTFPのブレーキペダルなど「奥のスプリング・ゴムが硬く、足の力では電気的最小値（0）まで押し込めない」場合や「ストロークの途中でRaw最小値に達してしまう」場合でも、**自分の足の最大踏み込み位置を100%として正確にマッピング**できます。
     - **入力ガンマ (Gamma / 入力カーブ) 調整**:
       - スライダー調整範囲: `0.5` 〜 `3.0`（`0.1` 刻み、デフォルト `1.0`）。
       - リアルタイム特性テキスト表示:
         - `1.0`: 「リニア (標準)」— 踏み込み量と出力が完全な1対1比例。
         - `> 1.0` (推奨 1.5〜2.2): 「プログレッシブ (奥で強く効く・踏み切り急増防止)」— 踏み始めから中間域（0〜70%）の感度が緩やかになり、ペダルを奥深く強く踏み込むことで100%に立ち上がる実車の油圧ブレーキ感覚。
         - `< 1.0`: 「ディグレッシブ (手前が敏感)」— 踏み始めに急激に立ち上がる設定。
       - **数理モデル**:
         $$\text{ratio} = \text{Clamp}\left(\frac{\text{rawValue} - \text{Raw0Percent}}{\text{Raw100Percent} - \text{Raw0Percent}}, \, 0.0, \, 1.0\right)$$
         上下デッドゾーンを除去した有効区間 $[dz_{min}, \, 1.0 - dz_{max}]$ において線形正規化 $x \in [0.0, 1.0]$ を計算後、ガンマ補正を適用:
         $$y = x^{\text{Gamma}}$$
       - **「100%踏み切っていないのに100%表示になってしまう」現象の根本解決**:
         リニア（Gamma=1.0）では、硬いブレーキペダルの中間ストロークで足の筋力と出力感覚が乖離し、「まだ奥があるのに画面上はすぐ100%に跳ね上がってしまう」感覚を受けます。ガンマを `1.8` 前後に設定することで、$50\%$ のストローク位置での出力が $0.5^{1.8} \approx 28.7\%$ に抑えられ、奥で渾身の力を込めて踏み込んだ時に初めて $100\%$ に到達する理想的なブレーキフィールが得られます。
     - **踏み始め遊び (0%側デッドゾーン)**:
       - スライダー調整範囲: `0%` 〜 `30%`（デフォルト `2%`）。
       - ペダルに足を軽く載せただけの微小な踏力や、ポテンショメータの残留ノイズによる誤入力を完全にカットします。
     - **踏み切り遊び (100%側デッドゾーン)**:
       - スライダー調整範囲: `0%` 〜 `30%`（デフォルト `2%`）。
       - ペダルの物理可動域の限界手前（例: 98%位置）で確実に100%入力に到達させます。これにより、ヒール＆トゥやフルブレーキング時に「力いっぱい踏んでいるのに97%で止まってしまう」という入力抜けを完全に防止します。
     - **ペダル設定を手動保存**:
       - 各入力・ボタン操作時に設定は即座にバックグラウンド自動保存されますが、明示的に手動保存を行いたい場合のボタンも完備。

5. **Signal Filter (信号フィルタ)**
   - **Filter Strength**: EMAスムージング強度（0%〜50%）。0%で遅延ゼロのダイレクト反映、数値を上げると微細な電気ノイズを平滑化。

## 4. 設定の保存仕様（Persistence）

アプリの設定はすべて以下のパスにJSON形式で永続化されます。

- **保存ファイルパス**: `%LOCALAPPDATA%\SteeringTrainer\settings.json`
- **保存タイミング**:
  - 設定画面で「適用 & 保存」または「ペダル設定を手動保存」を押したとき
  - 0%点・100%点設定ボタン（「未踏み(0%)に設定」「全踏み(100%)に設定」）を押したとき
  - 各ペダルの軸割り当て、Raw0/Raw100、反転、デッドゾーン、ガンマスライダーを変更したとき
  - ホイール回転角、センターオフセット、ステアリング反転、フィルタ強度を変更したとき
  - 「常に最前面」チェックボックスを切り替えたとき
  - タブを切り替えたとき（次回起動時に同じタブを開く）
  - アプリケーション終了時（`Closed` / `Dispose`）
- **保存内容（データ構造）**:
  - `SelectedDeviceId` / `SelectedDeviceName`: 選択デバイスID・デバイス名
  - `WheelRotation`, `CenterOffset`, `InvertInput`, `FilterStrengthPercent`: ステアリング設定
  - `Topmost`: 常に最前面表示状態
  - `SelectedTabIndex`: 選択タブインデックス
  - `PedalSettings`: 各ペダル（Throttle, Brake, Clutch）の詳細校正設定
    - `AssignedAxis`: 割り当て軸（`JoystickAxis`）
    - `Raw0Percent`: 0%点 Raw値（未踏み時）
    - `Raw100Percent`: 100%点 Raw値（最大踏み込み時）
    - `DeadzonePercent`: 踏み始め遊び（0%側）
    - `MaxDeadzonePercent`: 踏み切り遊び（100%側）
    - `Gamma`: 入力ガンマ指数（0.5〜3.0）
    - `Invert`: 反転フラグ（`Raw0Percent > Raw100Percent`）
    - ※ 旧バージョンの `MinRaw`, `MaxRaw` を含む `settings.json` とも完全な双方向下位互換を維持。
  - `HeelToeSettings`: ヒール＆トゥ練習設定（目標量、許容ブレ幅、フリーランダム設定、ランダム目標出現範囲制限［ブレーキ最低/最高値・アクセル最低/最高値］、難易度、効果音音量、手本表示、ブラインドモード設定）
  - `ThrottleTrackingSettings`: アクセル波形追従練習設定（目標ブレーキ量、ブレーキ許容幅、アクセルMin/Max、アクセル許容幅、波形速度BPM、波形周期秒数、練習時間秒数、メトロノームON/OFF、メトロノーム音量）

※ 過去の試行スコア履歴は `%LOCALAPPDATA%\SteeringTrainer\training-history.db`（SQLite）に自動記録されます。

## 6. セットアップと実行方法

### 必要な環境
- Windows 10 / 11 (64-bit)
- .NET 8.0 SDK または ランタイム
- DirectInput対応ステアリングコントローラー（GTFP, G29等）またはテスト用Syntheticデバイス

### 最速起動
フォルダ直下のバッチファイルを実行するだけで、バックグラウンドビルド（初回のみ）と起動が完了します。
```cmd
起動する.bat
```
または PowerShell から直接起動:
```powershell
powershell -ExecutionPolicy Bypass -File .\Launch.ps1
```

### CLI からの手動ビルドとテスト
```powershell
# .NET 8 によるソリューションのビルド (Release)
dotnet build SteeringTrainer.sln -c Release

# 単体テストの実行 (全39件のテスト全件合格)
dotnet test SteeringTrainer.Tests\SteeringTrainer.Tests.csproj

# アプリの起動
dotnet run --project SteeringTrainer.App\SteeringTrainer.App.csproj -c Release
```
